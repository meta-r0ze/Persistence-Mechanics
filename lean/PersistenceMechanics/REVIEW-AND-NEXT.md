# PersistenceMechanics — open work (todo)

There are no missing Lean proofs in the framework's stated scope. The three
premises of `HazardForm` are explicit inputs, not theorems: survival depends only
on accumulated cost through one function for all histories; consecutive stretches
multiply; and more cost never helps. The cost-proportional hazard and its common
`β` are derived from those premises.

Downstream physical identifications and model inputs are listed in each paper's
`REVIEW-AND-NEXT.md`.
